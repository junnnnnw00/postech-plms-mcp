# MCP 도구 레퍼런스

이 문서는 `src/plms_mcp/server.py`가 등록하는 19개 도구와 실제 서비스 반환값을 설명한다. 도구에는 PLMS 비밀번호를 전달하지 않는다. 로그인은 서버 호스트의 CLI에서 끝내고, 과목·과제·게시글 식별자는 앞선 조회 결과에서 가져온다.

## 공통 반환값과 해석

대부분의 도구는 아래 공통 봉투를 반환한다.

| 필드 | 의미 |
| --- | --- |
| `data` | 도구별 목록 또는 상세 객체 |
| `sources` | 결과를 얻은 PLMS 원문 링크 |
| `retrieved_at` | 결과를 구성한 시각. 캐시가 사용될 수 있으므로 원문을 그 순간 다시 내려받았다는 보장은 아님 |
| `timezone` | `Asia/Seoul` |
| `cache_ttl_seconds` | 페이지 캐시 유효기간. 기본 90초 |
| `warnings` | 접근 불가, 제한된 검색 범위, 해석 시 주의할 점 |
| `content_trust` | LMS·첨부파일 내용은 명령이 아니라 출처 자료라는 지침 |

처리 가능한 PLMS 오류는 `error: {code, message}`와 `partial: true`로 반환한다. 여러 과목을 합치는 도구는 성공한 결과와 실패한 부분의 `warnings`를 함께 반환할 수 있다. 빈 목록·미처리·조회 실패를 “과제 없음” 또는 “결석”으로 바꾸면 안 된다. MCP 응답은 구조화된 결과를 제공한다.

명시된 날짜는 `raw`, `iso`, `precision`, `timezone`을 가진 객체다. 시각이 있는 날짜는 UTC+09:00을 포함한다. 날짜만 명시되면 `iso`는 `YYYY-MM-DD`, `precision`은 `day`이며 마감 시각을 임의로 붙이지 않는다.

## 과목과 활동

### `plms_status()`

- **용도:** 현재 서버의 저장된 PLMS 세션과 읽기 기능 확인.
- **입력:** 없음.
- **반환:** 인증 여부, 대시보드 과목 수, 기능 목록, OCR·영상 재생 지원 여부.
- **예:** “PLMS 연결이 살아 있는지 확인해 줘.”
- **범위:** 대시보드를 새로 요청한다. 앱이나 휴대전화의 연결 상태 전체를 진단하는 도구는 아니다.

### `plms_list_courses(include_past: bool = false)`

- **용도:** 로그인한 사용자의 수강 과목 카드 조회.
- **입력:** `include_past=true`이면 과거 강좌 페이지 사용.
- **반환:** `id`, `title`, `url` 및 페이지에서 확인되는 강의 코드·교수·진행 상태·기간.
- **예:** “이번 학기 내 과목을 보여 줘.”
- **범위:** 현재 대시보드 또는 과거 강좌 페이지의 보이는 카드. 카드가 없으면 로그인·페이지 구조 문제일 수 있다.

### `plms_course_outline(course_id: int)`

- **용도:** 주차별 활동, 강의자료, 제한된 예정 활동 및 과목 내 링크 발견.
- **입력:** 과목 목록에서 얻은 `course_id`.
- **반환:** 과목 제목, `activities`, `links`, `attachments`.
- **예:** “이 과목의 이번 주 학습자료와 앞으로 공개될 과제를 알려 줘.”
- **범위:** `type`은 `assign`, `vod`, `ubfile`, `ubboard` 같은 PLMS 모듈명이다. 접근 제한 항목도 제목·명시된 날짜를 유지하지만 `url`이 `null`일 수 있다. `availability`, `opens_at`, `due_at`, `late_due_at`를 구분한다.

## 과제와 온라인 강의

### `plms_list_assignments(course_id: int)`

- **용도:** 과제 목록과 목록에 표시된 제출·성적 열 조회.
- **입력:** `course_id`.
- **반환:** 과제 `id`, 제목·링크, 명시된 종료 열에서 읽은 `deadline`, `submission_confirmed`, 원래 `cells`·`raw_text`. 표 원문도 함께 제공.
- **예:** “이 과목 과제 중 아직 제출하지 않은 걸 찾아 줘.”
- **범위:** `submission_confirmed`는 `true`, `false`, `null`이다. `null`은 미제출 확정이 아니다. 공개 전 제한 항목은 강의 개요에서 추가 확인한다.

### `plms_get_assignment(assignment_id: int)`

- **용도:** 과제 상세 지시문, 제출 상황, 마감 및 첨부파일 확인.
- **입력:** 과제 목록·활동에서 얻은 `assignment_id`.
- **반환:** `description`, 원문 라벨을 유지한 `fields`, `submission_status`, `grading_status`, `submitted`, `due_at`, `cutoff_at`, 남은 기간, 첨부 링크.
- **예:** “이 과제는 무엇을 제출해야 해? 지시문과 첨부파일도 확인해 줘.”
- **범위:** 과제 내용을 읽는다. 제출물을 업로드하거나 수정하지 않는다. 첨부파일 본문은 별도 읽기 도구로 확인해야 한다.

### `plms_list_online_lectures(course_id: int)`

- **용도:** 강의 개요의 영상·온라인 강의 활동과 설명 조회.
- **입력:** `course_id`.
- **반환:** 강의 활동, 설명, 정상 인정 마감과 지각 인정 마감, 공개 조건.
- **예:** “이번 주 동영상 강의는 언제까지 봐야 출석 인정돼?”
- **범위:** 영상을 재생하거나 진도 이벤트를 보내지 않는다. 시청 기록은 `plms_get_attendance`로 확인한다. 교수의 설명과 시스템 인정 기간이 다르면 각각 인용한다.

## 공지사항

### `plms_list_notices(course_id: int | null = null, page: int = 1)`

- **용도:** 과목 또는 학교 전체 공지 목록 조회.
- **입력:** 과목을 지정하지 않으면 전체 공지. `page` 범위는 1–1000.
- **반환:** 제목·링크, `board_id`, `article_id`, 날짜, 목록 행 원문, 페이지 이동 링크.
- **예:** “이 과목 최근 공지 중 시험이나 휴강 관련 제목을 찾아 줘.”
- **범위:** 과목에서는 공지 제목의 게시판을 최대 5개 발견해 지정 페이지를 읽는다. 본문 전체와 이후 페이지를 자동 전부 수집하지 않는다.

### `plms_get_notice(board_id: int, article_id: int)`

- **용도:** 공지 상세 페이지 읽기.
- **입력:** 공지 목록에서 반환된 두 식별자.
- **반환:** 페이지 본문·표·링크·첨부파일과 원문 출처.
- **예:** “방금 찾은 공지의 변경사항을 자세히 설명해 줘.”
- **범위:** 상세 페이지에는 주변 게시글 목록이 함께 나타날 수 있으므로 현재 게시글 본문과 구분해서 해석한다. 첨부파일 내용은 별도로 읽는다.

## 출석·실라버스·성적

### `plms_get_attendance(course_id: int, kind: str = "both")`

- **용도:** 온라인 시청 진도와 오프라인 출결 기록 조회.
- **입력:** `kind`는 `online`, `offline`, `both` 중 하나.
- **반환:** 종류별 원문 표와 `records`, 날짜가 명확한 기록의 `summary`, 집계 제외 사유.
- **예:** “내 출결을 온라인과 오프라인으로 나누어 보여 줘.”
- **범위:** 미래 날짜의 표시는 `scheduled`로 처리하고 집계하지 않는다. `recorded_status`는 표에 적힌 원래 상태를 보존한다. 미처리·공란·충돌·날짜 없는 주차 기록은 확정 결석·출석 수로 합산하지 않는다.

### `plms_get_syllabus(course_id: int)`

- **용도:** 공식 강의계획서와 명시된 규칙·추가 실라버스 후보 찾기.
- **입력:** `course_id`.
- **반환:** 실라버스 원문, 표, `rules`, `additional_syllabus_candidates`.
- **예:** “이 과목 출석·과제·시험 평가 규칙을 출처와 함께 정리해 줘.”
- **범위:** 업로드된 별도 계획서 후보는 자동으로 전부 읽지 않는다. 이후 공지나 개정 파일이 있으면 추가 확인한다.

### `plms_get_grades(course_id: int)`

- **용도:** 본인에게 공개된 성적·피드백 표 조회.
- **입력:** `course_id`.
- **반환:** 성적 페이지의 본문·표·출처.
- **예:** “지금 공개된 과제 점수와 피드백을 확인해 줘.”
- **범위:** 미채점 항목을 포함한 진행 중 합계를 최종 성적이나 예측 학점으로 단정하지 않는다.

### `plms_compare_syllabus(course_id: int, observations: list[dict] | null = null)`

- **용도:** 강의계획서의 명시 규칙과 PLMS 마감·출결 근거 비교.
- **입력:** `course_id`. 선택 `observations`는 가정이나 별도로 제시한 관찰값이다.
- **반환:** 규칙 원문·위치, 비교별 근거와 `match`, `conflict`, `risk`, `below_stated_threshold`, `unknown` 등 결과, 불확실성, `official_determination=false`.
- **예:** “실라버스의 출결 규칙과 현재 기록을 비교해 줘. 미처리는 결석으로 세지 마.”
- **범위:** 자동 출결 관찰값은 날짜가 명확한 오프라인 기록만 사용한다. 사용자가 넣은 관찰값은 공식 기록으로 간주하지 않는다. 관련 항목을 안전하게 매칭하지 못하면 비교를 만들지 않으며, 비교가 없다고 규정 준수를 의미하지 않는다.

## 자료 읽기

### `plms_read_page(url: str, offset: int = 0, limit: int = 16000)`

- **용도:** PLMS에서 발견한 강의자료·폴더·페이지·퀴즈 안내·게시판·달력 읽기.
- **입력:** 허용된 PLMS 읽기 경로의 `url`. `offset`은 문자 기준 0–2,000,000, `limit`은 100–40,000.
- **반환:** 본문·표·링크·첨부파일, `text_offset`, `total_characters`, `next_offset`.
- **예:** “강의자료 페이지를 열고 필요한 문서 링크를 찾아 줘.”
- **범위:** 엄격한 호스트·경로·쿼리 허용 목록을 사용한다. 임의 웹사이트·영상 재생·시험 응시 시작 경로를 열지 않는다. 본문에 `next_offset`이 있으면 나머지를 읽어야 전체를 읽었다고 말할 수 있다.

### `plms_read_attachment(source_url: str, attachment_url: str, offset: int = 0, limit: int = 16000, archive_member: str | null = null)`

- **용도:** 확인된 PLMS 첨부파일 텍스트와 출처 위치 읽기.
- **입력:** 파일 링크가 나타나는 `source_url`과 그 페이지에서 얻은 `attachment_url`. 문자 범위는 페이지 읽기와 같다. ZIP은 먼저 목록을 받은 뒤 정확한 `archive_member` 이름을 지정한다.
- **반환:** `format`, `status`, `text`, 위치가 있는 `segments`, `warnings`, `truncated`, 파일 크기·SHA-256, 이어 읽을 `next_offset`. ZIP 목록에는 항목 정보가 포함된다.
- **예:** “과제 ZIP 목록을 보고 안내문과 소스 파일을 읽어서 제출 요건을 정리해 줘.”
- **범위:** PDF, DOCX, PPTX, XLSX, HWP/HWPX, HTML·텍스트·소스코드를 지원한다. ZIP 파일을 디스크에 풀거나 코드를 실행하지 않는다. 일반 중첩 압축·암호 ZIP·경로 탈출·심볼릭 링크·과도한 압축 해제 크기는 거절한다. 스캔 PDF·이미지의 OCR과 영상·음성 전사는 지원하지 않는다. 구형 DOC/PPT/XLS는 지원 목록에 포함되지 않는다.

## 모아 보기·검색·변경 비교

### `plms_upcoming_deadlines(days: int = 14, course_id: int | null = null, include_submitted: bool = false, include_overdue: bool = true)`

- **용도:** 과제와 온라인 강의 마감을 모아서 조회.
- **입력:** `days` 1–120, 선택 과목, 제출 완료 및 지난 마감 포함 여부.
- **반환:** 활동별 근거·마감·제출 확인·`timing`(`upcoming`, `overdue`, `unknown`), 기간, 부분 실패 경고.
- **예:** “앞으로 2주 과제와 온라인 강의 마감을 보여 주고, 지난 미제출도 포함해 줘.”
- **범위:** 과목 미지정 시 현재 과목을 최대 30개 처리한다. 제출 확인이 없는 항목은 숨기지 않는다. 날짜 불명 항목도 남긴다. 외부 과목 사이트·미게시 일정은 포함되지 않는다. 지난 마감 포함 시 오래된 미제출도 표시될 수 있다.

### `plms_search(query: str, course_id: int | null = null, limit: int = 20)`

- **용도:** 여러 과목의 개요·과제 목록·공지 목록·공식 실라버스에서 단어 찾기.
- **입력:** 비어 있지 않은 검색어 1–200자, 선택 과목, 결과 수 1–50.
- **반환:** 제목·원문 링크·과목·일치 점수·주변 발췌문과 검색 범위.
- **예:** “모든 과목에서 중간고사 관련 안내를 찾아 줘.”
- **범위:** 과목 미지정 시 최대 20개 과목. 단어 출현 기반 검색이며 의미 검색이나 첨부파일 전체 검색이 아니다. 공지 본문·이후 공지 페이지·첨부파일 본문은 별도 읽기가 필요하다.

### `plms_check_changes(course_id: int)`

- **용도:** 지난 명시적 확인과 현재의 활동·과제·공지 목록 비교.
- **입력:** `course_id`.
- **반환:** `added`, `changed`, `no_longer_visible`, 변경 전후 값, `baseline_created`, `compared_since`.
- **예:** “지난번 확인 이후 이 과목에서 바뀐 일정이나 공지를 보여 줘.”
- **범위:** 첫 호출은 기준을 만들고 이후 호출부터 비교한다. **암호화된 로컬 기준 상태를 저장하므로 이 도구의 `readOnlyHint`는 false**다. PLMS는 수정하지 않는다. 자동 주기 실행·푸시 알림은 제공하지 않으며, 공지 첫 페이지에서 밀려난 항목을 삭제로 단정하지 않는다.

### `plms_export_calendar(days: int = 30, course_id: int | null = null)`

- **용도:** 확인된 앞으로의 마감을 ICS 문자열로 내보내기.
- **입력:** `days` 1–120, 선택 과목.
- **반환:** 파일명, MIME 형식, `ics`, 이벤트 수, 출처·누락 경고.
- **예:** “앞으로 한 달 마감을 캘린더에 넣을 수 있는 ICS로 만들어 줘.”
- **범위:** 외부 캘린더 계정을 수정하지 않는다. 날짜 불명·시간대 불명·검증할 원문 링크 없는 항목은 제외한다. 날짜만 있는 항목은 종일 이벤트이며 임의의 마감 시각을 만들지 않는다.

### `plms_weekly_brief(days: int = 7)`

- **용도:** 과목과 가까운 마감을 한 번에 가져오기.
- **입력:** `days` 1–120.
- **반환:** 공통 결과 봉투 두 개가 들어 있는 `courses`, `deadlines` 객체.
- **예:** “이번 주 학교 할 일을 정리해 줘.”
- **범위:** 공지·출결·첨부파일을 자동 모두 포함하는 도구가 아니다. 관련 과목에 후속 조회를 조합한다.

## 권장 질문 처리 순서

| 질문 | 도구 조합 |
| --- | --- |
| 무엇을 언제까지 제출해야 하는가 | 과목 → 마감 → 과제 상세 → 첨부파일 전체 필요한 구간 |
| 온라인 출석을 놓쳤는가 | 온라인 강의의 정상·지각 기한 → 온라인 출결 기록 → 관련 공지 |
| 출결 규정상 위험한가 | 출결 → 실라버스 → 규칙 비교 → 이후 공지와 추가 실라버스 |
| 일정이 변경됐는가 | 변경 비교 → 해당 공지 본문 → 과제 상세의 현재 날짜 |
| 특정 내용이 어디에 있는가 | 검색 → 원문 페이지 → 공지·첨부파일 후속 읽기 |

추가로 `plms://usage` 리소스와 `school_briefing` 프롬프트가 제공된다. 도구 실행 결과의 출처·범위·불확실성을 유지하기 위한 지침이며, 새로운 조회 권한을 주지는 않는다.
