# 검증 기록

기록일: 2026-09-28, 한국 시간. 공개 기록에는 계정 정보, 학교 과목·과제·학생 원문, 실제 식별자와 개인 자료 URL을 포함하지 않는다. 아래 성공 항목은 사용자 승인 계정에서 확인한 범위이며 모든 학교 계정·과목·파일 형식의 완전한 호환성을 의미하지 않는다.

## 실제 계정과 전송 계층

| 항목 | 확인한 결과 |
| --- | --- |
| 사용자 승인 계정의 학교 SSO | 로그인 성공 및 PLMS 세션 확인 |

| 과제 | 과제 목록·상세와 제출 상태·명시된 마감의 서비스 호출 성공 |

| HTTPS 인증 경계 | 임시 Cloudflare HTTPS 터널에서 익명 `/mcp` 요청의 401 거부와 OAuth 메타데이터 확인 |
| 원격 OAuth | 실제 HTTP에서 OAuth·PKCE 인증과 토큰 폐기 확인 |

| ChatGPT 개인 원격 plugin | 실제 브라우저 OAuth 승인 후 Connected accounts에 개인 PLMS 계정 표시 확인 |
| ChatGPT 웹 실제 질문 | 연결된 plugin으로 수강 과목을 요청하여 실제 과목 8개와 출처·조회 시각이 포함된 자연어 답변 확인 |

서비스 호출 성공, HTTP 프로토콜 시험, 모델의 자연어 답변 품질, 모바일 연결 성공은 서로 다른 검증이다. 위 결과는 확인한 서비스와 호출의 동작을 증명하며, 19개 전체 도구의 모든 실제 자료 조합이나 휴대전화 실기기 호출 완료를 뜻하지 않는다.

## 합성 데이터 테스트

공개 테스트는 합성 HTML·문서·네트워크 응답을 사용한다. 실제 학생 자료나 로그인 비밀을 fixture로 배포하지 않는다. 테스트 개수는 개발 중 늘어날 수 있어 이 문서에 고정하지 않으며, 현재 실행 결과로 확인한다.

```sh
python -m pytest
```

테스트 범위에는 다음이 포함된다.

- SSO·쿠키·저장 상태와 세션 오류 처리.
- 허용 URL, 리다이렉트, 응답 크기 및 인증 경계.
- 날짜 정밀도, 한국 시간, 정상·지각 기한과 공개 조건의 분리.
- 숨겨진 HTML·스크립트 제거, URL 비밀 제거, 문단·표 문맥 보존.
- 제출 미확인과 미제출 구분, 미래 출결과 실제 기록의 구분.
- 문서 원문 위치, 문서·ZIP 제한 및 지원하지 않는 형식 처리.
- 실라버스 규칙의 수치 조건, 예외, 불완전 기록과 비교 결과의 불확실성.
- OAuth 승인·PKCE 통합·resource·토큰 갱신·폐기와 재사용 방어.
- 마감·검색·변경 비교·ICS 등 서비스 조합과 MCP 응답.

각 범위의 정확한 사례는 `tests/`의 현재 테스트를 기준으로 한다. 테스트 통과는 실제 PLMS 페이지 변경이나 배포 환경 차이를 자동 검증해 주지 않는다.

## 아직 완료로 기록하지 않은 사항

| 항목 | 이 기록 시점의 상태 |
| --- | --- |
| 휴대전화에서 실제 PLMS 도구 호출 | 미검증. ChatGPT 계정 연결은 완료했으며 같은 계정의 휴대전화에서 호출 확인 필요 |
| 지속 가능한 고정 호스팅 | 미완료. 임시 터널과 구분 |
| 다른 학생의 계정 | 미검증. 학생별 개인 인스턴스 설치 방식 |
| 모든 첨부 형식의 실제 학교 파일 | 형식별 합성 테스트와 실제 자료 확인 범위를 구분해야 함 |
| OCR·영상 시청·과제 제출 | 제공 기능이 아니므로 수행하지 않음 |

임시 HTTPS endpoint는 개인 테스트 주소로 공개 문서에 싣지 않는다. 서버 또는 터널이 종료되면 호출할 수 없으며, 고정 호스팅의 가동 지속성을 검증한 상태도 아니다. 데스크톱 설정 등록만으로 일반 모바일 Chat/Work에 plugin이 자동 설치되지는 않는다. [연결 문서](clients.md)의 개인 원격 plugin 또는 Remote 절차를 따른다.

## 다음 검증을 추가하는 방법

새 환경에서 확인할 때는 날짜, 소스 버전, 전송 방식, 기능명, 성공·실패·미검증을 기록한다. 원문 학생 자료·쿠키·토큰·개인 주소는 공개 결과에서 제외한다. 여러 계정을 지원한다고 발표하려면 계정 간 자료 격리를 별도로 검증해야 하며, 현재 단일 소유자 설계를 다중 사용자 서비스 검증으로 대체할 수 없다.
